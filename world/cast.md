# Shared Fictional Cast

Games run in a **parallel October 2026**: real-world history up to T0 happened as in [research/world-baseline.md](../research/world-baseline.md), but frontier labs are fictional composites. There is deliberately **no one-to-one mapping** to real companies — each composite blends traits from several. Real-world incidents are referenced in-game as "the 2026 sandbox-escape incident at a leading lab", etc.

Countries, real public institutions (Congress, courts, DoD, PLA, EU Commission) appear as themselves, played as institutions. Individuals appear only as roles.

Scenarios can override or add to this cast, but should reuse it where possible so cross-game insights compare like with like.

## US frontier labs

| Name | Profile |
|---|---|
| **Meridian** | Safety-branded frontier lab; largest enterprise share; recently in conflict with the national-security establishment over usage red lines; pre-IPO. Internal R&D heavily automated. Strong safety team, commercial pressure rising. |
| **Helix** | Largest consumer footprint (~1B weekly users); aggressive release cadence; leading in AI-R&D automation claims; deep government/defence contracts; recently had a containment incident; raising at ~$1.4T. |
| **Lumen** | Division of a trillion-dollar tech conglomerate; huge compute, own chips; slower, more process-heavy; search/ads/phone distribution. |
| **Vanta** | Part of a founder-controlled conglomerate spanning launch, satellites, social media and AI; massive compute; founder has outsized personal control and political ties; lagging slightly at the frontier. |

## Model naming

Each lab's models are named `<Lab>-<generation>` in-game (e.g. `Meridian-6`, `Helix-7`) unless a scenario needs otherwise.
